# DiscordOllamaBot

A collaborative AI group chat bot for Discord, powered by Ollama.

## Install
1. Install [Ollama](https://ollama.com/) and run `ollama run llama3` to ensure the model is available.
2. Install DiscordOllamaBot:
   ```sh
   ./setup.sh install
   ```
   
## Run
   ```sh
   ./setup.sh run
   ```
